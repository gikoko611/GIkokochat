Privacy & safety

This is a browser-based starter. API keys are saved in this browser's localStorage for convenience; this is not encrypted secure storage. Do not use on a shared device. For production, route API requests through a backend and use OS-backed secure storage.

⚿ API Key Manager

Use your own provider key. Keys are stored only in this browser for this prototype. Provider availability, model names, usage limits and billing depend on your account.

Supported connection types

OpenAI-compatible Chat Completions endpoints can often work with a custom base URL. Some providers require their own API format and may not work through this generic starter.
